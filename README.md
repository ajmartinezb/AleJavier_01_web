# AleJavier_01_web

Libros de estudio PAES escritos en Markdown y publicados como sitio HTML.

- **Biología PAES**: `biologia/`. El sitio generado está en `biologia/sitio/index.html`. Ver `biologia/pauta.md` y `biologia/progreso.md`.
- **Física PAES**: `fisica/`. El sitio generado está en `fisica/sitio/index.html`. Ver `fisica/pauta.md` y `fisica/progreso.md`.
- **Portal**: `index.html` → `inicio.html` → `ramo.html?id=…`.

Para generarlos: `pip install -r requirements.txt`, luego `python herramientas/construir.py biologia` y `python herramientas/construir.py fisica`.

**Para seguir trabajando con Google Gemini**, lee `guia-gemini/GUIA.md`. Gemini CLI lee solo `GEMINI.md`.
